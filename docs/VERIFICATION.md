## How to re-run

```sh
node scripts/verify.mjs                          # build + every step, about 17 minutes
node scripts/verify.mjs --skip-build --steps=perf  # one step against the current dist/
node scripts/verify.mjs --skip-build --steps=demo,demobuild  # the closers' demo day and the demo build only
node scripts/verify.mjs --skip-build --steps=leads  # the Leads page: mock, then real mode against the stand-in box
```

Port 5185 must be free (VERIFY_PORT overrides). Lighthouse is fetched by npx into VERIFY_SCRATCH (default the OS temp folder), never into the project. Both servers are stopped before the script exits.
